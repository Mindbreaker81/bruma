Qué incluye la versión actual

  • Nuevo, abrir, guardar y guardar como (.md / .markdown)
  • Editor Markdown (CodeMirror 6)
  • Vista previa en tiempo real (markdown-it + DOMPurify)
  • Modos: editor, vista previa, dividido
  • Búsqueda con contador y navegación
  • Protección ante cambios sin guardar
  • Arrastrar y soltar archivos Markdown
  • Recientes persistidos con menú nativo
  • Tema claro / oscuro / sistema
  • Interfaz bilingüe es / en
  • Menú nativo de aplicación
  • Carga diferida de módulos pesados

Seguridad y privacidad

  • Local-first estricto: sin nube y sin telemetría
  • Sanitización del HTML de la vista previa
  • CSP de Tauri endurecida en el build de escritorio
  • Lectura/escritura Markdown restringida al home del usuario tras canonicalización de rutas
